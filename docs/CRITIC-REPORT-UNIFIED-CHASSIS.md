The review inspected current source and saved actual GPU images independently, ran the geometry probe, and made fresh loopback production HTTP requests. Browser operation and image capture were performed by the implementation agent. The critic did not operate a separate browser or physical phone. Numerical extraction from the saved browser records is corroboration of that evidence, not a second browser test.

The preservation audit compares vessel-relative room placement, state-current geometry, material and texture drawing commands/transforms, shader hooks, render flags, instances/lights, visibility and navigation metadata. Ten specifically named outer chassis objects are exempted, with restricted room membership and expected counts; no complete room is waived. It also requires the static batching code to remain unchanged. The passing fixture result supports the required cabin preservation. It does not imply identical GPU font rasterization or shadows, since the new chassis can cast different shadows. See the [exact exemptions](evidence/unified-chassis/chassis-exclusions.json) and [audit source](../scripts/chassis-preservation-audit.mjs).

The independent geometry execution checks 104 front-aperture samples, 126 center-web samples, 108 directed side-passage samples, 416 roof/keel coverage samples across depth joins, and 36 blind-recess floor samples. Visible chassis, docking, service and ladder coordinates are finite, normals have unit length, and bounds fit the declared overview. It also verifies that source did not change during execution. Reproduce it with:

```sh
node scripts/chassis-geometry-audit.mjs . components/spacecraft-model.ts docs/evidence/unified-chassis/chassis-geometry.json
```

The final production browser records preserve the actual native gesture results, travelled routes and renderer identity. The separately collected [development ladder trace](evidence/unified-chassis/ladder-crossing-trace.json) contains 106 finite-transform samples over approximately 2.47 seconds, with the camera entering the left walkway and settling in About; all recorded room light levels remain in the allowed 0.5–1 range. This is explicitly development trace evidence, because production raw tracing is disabled. The independent inspection of captured corner projections found the desktop, both oblique views and both portrait overviews inside their recorded safe rectangles. The selected portrait camera retains the existing width-first compromise: the full rack fits, with surrounding structure and part of an adjacent cabin visible. That behavior was not redesigned in this chassis-only scope.

Independent HTTP requests on the rebuilt local Worker returned 200 for five routes and all 11 directly referenced CSS/JS assets. The final [build](evidence/unified-chassis/build.txt), [typecheck](evidence/unified-chassis/typecheck.txt) and [lint](evidence/unified-chassis/lint.txt) logs pass. These are local production-build checks, not a claim that the separate historical hosting incident is resolved.

The [final production frame samples](evidence/unified-chassis/frame-samples.json) record 16.7 ms median animation-frame intervals for desktop captures and approximately 32.4–33.7 ms p95 at 1440×1000, effective DPR 1. Individual windows include zero to four intervals above 50 ms; overlapping windows must not be summed into unique stutters. The portrait captures record 16.7 ms medians and 18.5–18.6 ms p95 at effective DPR 1. These are shared desktop-host animation-frame intervals, not GPU execution times, physical-device results, evidence of a causal speedup, or a universal 60-fps guarantee. The modest measured geometry increase is acceptable for the achieved structural improvement, but performance beyond these tested conditions remains unverified.

The earlier faceted shoulder shading was a concrete finish issue and was re-reviewed after correction. No remaining chassis defect in the current source, clearance checks, production views or tested navigation requires another implementation change for this scoped acceptance. The score leaves room for finer surface treatment and broader hardware validation without treating those unverified conditions as passing.
