## Arrow rationale and remaining limits

Reversing ordinary arrows to up is a reasonable design choice for “continue through this doorway,” particularly with a ladder pictogram distinguishing deck travel. It is not a universal standards correction. [Canada's Federal Identity Program Manual, §4.3](https://www.canada.ca/en/treasury-board-secretariat/services/government-communications/federal-identity-program/manual.html), selects up at/below eye level and down for overhead straight-ahead signs. [PANYNJ's Wayfinding Manual v1.2, §6.2.4](https://wayfinding.panynj.gov/pa-cms/wp-content/uploads/2024/09/PANYNJWayfindingManual-Print-1point2.pdf), permits down where nearby level changes could make up ambiguous and uses circulation pictograms for level changes. These are precedents from specific public sign systems, not a compliance claim for this fictional spacecraft.

The most visible remaining limit is narrow-screen legibility: the physical doorway signs become small and foreshortened, so the native dropdown remains helpful. The current selected-phone composition also includes neighboring structure; this preserves the existing camera framing and is not a new defect caused by the rounded shell. Fine lettering may still show subpixel aliasing. The unchanged portrait pullback/rotation pacing and stylized clouds remain polish opportunities, without a new measurement or deferred-feature deduction in this pass.

This evidence does not establish native physical-touch performance, OS screen-reader behavior, a new full accessibility audit, every rapid retarget/orientation combination or low-end-device frame rate. No broad deferred-interface checks were performed to raise the score. The historical remote-hosting registration incident remains separate; this report does not claim a new public deployment.

The [independent state script](evidence/rounded-nose-lighting/critic-state-check.mjs) is reproducible with the installed Three.js package and Node TypeScript support, accepts repository root and output-path arguments, and passes oxfmt and targeted oxlint. All report evidence is packaged with the repository.
