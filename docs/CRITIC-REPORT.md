## Remaining limits, not claimed as verified

The final images and local browser measurements substantiate this implementation, not mockup-level offline rendering or performance on every device. Manual VoiceOver/NVDA, physical iOS/Android keyboard/touch behavior, low-memory GPU pressure, real-network startup and field Core Web Vitals remain unverified. The high Earth tier is deliberately expensive to meet the revised visual request; reading mode and lower tiers are real mitigations, not measured substitutes for those missing device checks. The default content is explicitly fictional/sample material and still needs the owner's real history before public launch.

A separate, pre-existing remote hosting incident remains unresolved: Sites deployment failed while registering the SIWC callback with HTTP 409 before issuing a deployment URL. `docs/OPERATIONS.md` records it. This local revision does not establish a deployed public site, working public DNS, or live hosted SIWC authentication, and this report must not be cited as doing so. It is not a new blocker in the explicitly local modification scope.

Initial effort is higher because the physical CSS3D/Three.js integration, picking, camera and accessibility fallback are custom. Ongoing content maintenance is isolated in the database/admin; procedural scene source and local assets avoid dependence on a proprietary model editor. Framework and hosting/auth upgrades still require engineering review.
