# Connected cabins checkpoint

This checkpoint widens desktop cabins, standardizes the four decks, removes the static project stand, adds empty project recesses and physical route hatches, and introduces bounded pointer dragging. Demo badges are now gated by demo/private mode. Pause was removed; Reading view is the motion-free alternative.

Typecheck, lint, production build and 20 workflow tests pass. Geometry and framing audits plus actual mouse-drag, hatch-navigation, five/zero-project restoration and mobile-reader evidence are in `docs/evidence/connected-cabins-revision`.

This is an intermediate checkpoint, not an independently accepted final revision. The user subsequently requested an open C-shaped route through a left walkway, deeper dimming, improved clouds/spare bays, and bottom navigation. Those requests supersede the closed vertical hatches in this checkpoint.
