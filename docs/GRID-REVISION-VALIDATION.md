## Performance and tradeoffs

The procedural environment removes all Earth image downloads. Its generated texture payload is 436,908bytes desktop and 76,460bytes mobile, compared with the previous highest image tier's244.82MiB. Geometry, framebuffers, driver overhead and the shared1KiB Three.js lookup are additional. Shader evaluation still costs GPU time: memory savings alone are not an FPS claim. Full desktop scenes use roughly 130–140 color calls, with additional cached shadow/contact work. Use clean runtime samples for cadence; development tracing adds overhead.

`production-measurements.json` measures six built-Worker routes and actual generated chunk sizes. These are warm loopback response times and computed gzip sizes, not network, field Core Web Vitals or physical-device results. Full content and metadata remain server-rendered without requiring 3D. Reading view removes the renderer; reduced motion and Pause stop simulation, and hidden/offscreen states suspend frames.

Procedural assets and a single metadata contract require more initial engineering, but owners can add/reorder/publish content without scene edits or specialized art software. The generated atmosphere has less photographic detail than a satellite composite and substantially smaller memory/transfer requirements. The current server is local only; the earlier remote Sites SIWC callback409 incident remains documented in OPERATIONS.md. No new public deployment is claimed.
