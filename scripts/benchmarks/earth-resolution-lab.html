Method and limits

All four variants load before the initial 20-second rest. First-load import, readiness, shader preparation and first complete render are reported separately. For first-load measurements, reload and start without previewing. Each block warms up for 10 frames, then measures the selected frame count. GPU queries cover only background rendering; updates and CPU submission are logged separately. Disjoint, hidden-tab, resize and stopped runs are explicitly recorded. Each satellite asset must decode at its requested dimensions; fallback rendering is rejected. The original procedural variant has no Earth image. Optional native thermal context is collected outside timed frames; elevated pressure or changed power mode/source invalidates a round. Unsupported native telemetry is marked unknown. No temperature or power savings are inferred. All four environments remain resident during measurement; this uses more memory than the live site.
