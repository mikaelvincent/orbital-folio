# Notebook handwriting

The notebook uses **Edu NSW ACT Foundation**, designed by Tina Anderson and
Corey Anderson for the AU School Handwriting Fonts project. The Latin WOFF2
contains the variable weight range 400–700 and is redistributed unchanged under
the [SIL Open Font License](OFL.txt).

- [Upstream project](https://github.com/MezMerrit/AU-School-Handwriting-Fonts)
- [Google Fonts metadata](https://github.com/google/fonts/blob/main/ofl/edunswactfoundation/METADATA.pb)
- [Original WOFF2](https://fonts.gstatic.com/s/edunswactfoundation/v5/raxsHjqJtsNBFUi8WO0vUBgc9D-2lV_oQdCASFdXsM6rDks.woff2)
- SHA-256: `e0d33cf585cf01d97bad579ca19b54eb43f65a49a993692884ffe1060f3ce882`

`../notebook-font.css` serves the local font from the same origin, preserving the
application's font content security policy. The page-image capture imports that
processed stylesheet and embeds the font bytes into the SVG; external font URLs
inside an SVG image cannot reproduce the measured ink.
There are no Google Fonts requests from the application.
